PROJECT 3: Angular PWA ERP BI Portal

HOW TO RUN:
1. Open this folder in VS Code.
2. Open the terminal.
3. Run: npm install
4. Run: npm start
5. Open: http://localhost:4200

HOW TO TEST PWA:
1. Run: npm run serve:pwa
2. Open: http://localhost:8080
3. Check Chrome DevTools > Application > Manifest and Service Workers.

CSV FILES ARE HERE:
src/assets/data

PROJECT INCLUDES:
- Angular components for Home, Finance, Sales, Customers, Production, and Supply Chain
- Angular service for loading CSV files
- Chart.js charts
- PapaParse CSV parsing
- Bootstrap responsive layout
- PWA manifest and service worker config
